# 📒 دفتر — برنامج محاسبة بسيط بالعربي

برنامج محاسبة للمحلات والشركات الصغيرة، يعمل من المتصفح ويُثبَّت على الموبايل والكمبيوتر كتطبيق (PWA)، **ويعمل بدون إنترنت**.
لا يحتاج سيرفر ولا قاعدة بيانات: كل البيانات محفوظة على جهاز المستخدم.

## ✨ الميزات

| القسم | ما يقدّمه |
|---|---|
| 🧾 الفواتير | مبيع، شراء، مرتجع مبيع، مرتجع شراء — نقدي أو آجل، حسم، **سعر المستهلك** لكل مادة، طباعة مع **تفقيط المبلغ** |
| 💱 العملات | **الليرة السورية والدولار** — كل فاتورة أو سند بعملته وسعر صرفه، والحسابات تُرحَّل بالليرة تلقائياً |
| 💵 السندات | سند قبض وسند دفع مع طباعة |
| 👥 العملاء والموردون | أرصدة فورية، رصيد افتتاحي، كشف حساب بضغطة |
| ▮▯▮ الباركود | **أكثر من باركود لكل مادة**، مسح بالفاتورة بقارئ باركود أو **بكاميرا الموبايل** (Chrome أندرويد)، والمسح المتكرر يزيد الكمية |
| 📦 المستودع | كميات فورية، كلفة **بالمتوسط المرجّح**، تنبيه الحد الأدنى، بطاقة مادة |
| 📒 دليل الحسابات | شجرة حسابات قابلة للتعديل (رئيسي / فرعي) |
| 📝 القيود اليومية | قيود يدوية مع فحص التوازن + عرض القيود المولّدة تلقائياً |
| 📊 التقارير | كشف حساب، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، جرد المستودع، بطاقة مادة، أرباح المواد، أرصدة العملاء والموردين |
| ☁️ السحابة | مزامنة بين كل الأجهزة عبر Supabase (اختياري)، يعمل بدون إنترنت ويرفع التغييرات عند عودة الاتصال، وإضافة مستخدمين |
| ⚙️ الإعدادات | بيانات المنشأة، العملة، نسخ احتياطي واستعادة (JSON)، بيانات تجريبية |

### كيف تعمل المحاسبة؟
- **قيد مزدوج** تلقائي: كل فاتورة وسند يولّد قيده بنفسه (لا يمكن أن يختل الميزان).
- **جرد مستمر**: فاتورة المبيع تسجّل المبيعات وتكلفة البضاعة المباعة معاً، فالربح يظهر فوراً.
- تعديل أو حذف فاتورة قديمة يعيد حساب كل شيء (الأرصدة والكلفة) تلقائياً.

## 🚀 النشر على GitHub Pages (مجاناً)

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `daftar`).
2. ارفع كل ملفات هذا المجلد إلى المستودع (من زر **Add file → Upload files**، أو عبر git):
   ```bash
   git init
   git add .
   git commit -m "first version"
   git branch -M main
   git remote add origin https://github.com/USERNAME/daftar.git
   git push -u origin main
   ```
3. في المستودع: **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. بعد دقيقة يصبح التطبيق على: `https://USERNAME.github.io/daftar/`

### التثبيت على الموبايل
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ☁️ تفعيل المزامنة السحابية (اختياري)

1. أنشئ حساباً على [supabase.com](https://supabase.com) ثم **New Project**.
2. من القائمة الجانبية: **SQL Editor** ← New query ← الصق محتوى ملف `supabase.sql` كاملاً ← **Run**.
3. (يُنصح به) **Authentication ← Sign In / Providers ← Email** ← أوقف **Confirm email** حتى لا يحتاج كل مستخدم لتأكيد بريده.
4. من **Project Settings ← API** انسخ: `Project URL` و المفتاح العام (`anon` أو `publishable`).
5. في التطبيق: الإعدادات ← المزامنة السحابية ← الصق القيمتين ← أنشئ حساباً ← «إنشاء ورفع بياناتي».
6. على أي جهاز آخر: نفس الخطوة 5 لكن اضغط «دخول» ثم «فتح» الشركة.

> لتجنّب إدخال الرابط والمفتاح على كل جهاز، ضعهما في ملف `config.js`. المفتاح العام آمن للنشر؛ الحماية مضبوطة داخل قاعدة البيانات (Row Level Security): لا أحد يرى بيانات شركة ليس عضواً فيها.

## 🧑‍💼 نقطة البيع لموبايل المندوب

1. من موبايل المدير: الإعدادات ← **📷 باركود نقطة البيع** ← اكتب اسم المندوب.
2. المندوب بيصوّر الباركود ← بيطلعله «بانتظار تفعيل المدير» (بلا إيميل ولا كلمة سر).
3. على موبايل المدير بيطلع شريط «📲 موبايل … بدو يفتح نقطة البيع» ← **✓ تفعيل**.
4. موبايل المندوب بيفتح نقطة البيع بس. للإيقاف: الإعدادات ← موبايلات نقطة البيع ← ⛔ إيقاف.

> هالميزة بتحتاج تشغيل `supabase.sql` من جديد (مرة وحدة) وإطفاء **Confirm email**.

## 🗂 هيكل الملفات

```
index.html      الصفحة الرئيسية والقائمة
styles.css      التصميم (RTL، متجاوب مع الموبايل، تنسيق الطباعة)
app.js          كل منطق البرنامج (الحسابات، الفواتير، التقارير…)
cloud.js        المزامنة السحابية مع Supabase
config.js       (اختياري) رابط ومفتاح Supabase
supabase.sql    إعداد قاعدة البيانات السحابية
sw.js           Service Worker للعمل بدون إنترنت
manifest.json   إعدادات تثبيت التطبيق
          الأيقونات
```

لا يوجد أي build أو مكتبات خارجية — عدّل الملفات وارفعها مباشرة.
للتجربة محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.

## ⚠️ ملاحظات مهمة
- البيانات محفوظة في متصفح الجهاز (localStorage). **مسح بيانات المتصفح يمسحها** — خذ نسخة احتياطية من الإعدادات بانتظام.
- كل جهاز له بياناته الخاصة؛ لنقلها استخدم النسخ الاحتياطي ثم الاستعادة على الجهاز الآخر.
- عند تحديث الملفات على GitHub، غيّر رقم `CACHE` في `sw.js` (مثلاً `daftar-v4`) ليصل التحديث للمستخدمين.
