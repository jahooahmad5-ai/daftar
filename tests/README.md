# 🧪 فحوصات دفتر

بتشتغل لحالها على GitHub مع كل تعديل (تبويب **Actions**). إذا فشل شي، بيطلع ❌ حدّ التعديل.

| الملف | شو بيفحص |
|---|---|
| `access.test.js` | شاشة القفل، موبايل المدير، باركود نقطة البيع، موبايل المندوب، دخول المدير، نقل وضع البيّاع القديم، المندوب الموقوف، خروج ومسح، إعادة ربط موبايل خسر جلسته، حفظ المبيعات يلي ما ارتفعت |
| `sales.test.js` | صندوق المندوب، القبض من زبون، الاستلام من المندوب، الترقيم بين جهازين، تصليح الرقم المكرر، التسعير حسب الزبون، مسودة الفاتورة، زر +، زبون جديد من الفاتورة، السعر بالقديم ببطاقة المادة، الفاتورة الجديدة بتفتح فاضية، ما في طلعة من الفاتورة إلا بالحفظ أو الحذف |
| `storage-print.test.js` | نقل البيانات لـ IndexedDB والبيانات الكبيرة، النسخ الأوتوماتيكية والرجوع، أوامر الطابعة (عادي وسريع)، إيصال السند، الآلة الحاسبة |
| `security.test.js` | بيانات ملغومة جاية من السحابة أو من رابط ما بتشغّل كود، «بيانات تجريبية» ممنوعة مع السحابة، نسخة قبل «مسح الكل»، دفعة فاتورة الدولار |
| `debts.test.js` | الديون: بس المديونين، أعمار الديون (الدفعة بتسدّ الأقدم أول)، قبض دفعة من الصفحة، موعد السداد وسقف الدين (وتحذير بالفاتورة)، تذكير واتساب، المندوب ممنوع |
| `custprofit.test.js` | تقرير أرباح الزباين: المبيعات والكلفة والربح لكل زبون (مع المرتجعات)، الأكثر ربحاً والأكثر سحباً، تحذير «بيسحب كتير بربح قليل»، الترتيب |
| `pos-home.test.js` | الرئيسية: فواتير نقطة البيع لليوم بجدول لحالها (المبيعات، المقبوض، وقديش زاد على حسابات الزباين) |
| `small.test.js` | تبويبين مفتوحين بنفس الوقت، ترقيم قيود الرصيد الافتتاحي من السيرفر، السرعة مع آلاف الفواتير (والأرصدة بتطابق الحساب اليدوي) |
| `whatsapp.test.js` | واتساب: أول مرة شاشة تأكيد وبعدها إرسال مباشر على رقم الزبون، رقم تغيّر أو «اسألني كل مرة»، سند القبض بالواتساب (والمندوب بلا رصيد)، صندوق الإرسال: المندوب بيبعت «من موبايل المدير» والمدير بيبعتها من رقمه مع الرصيد، الفاتورة والسند كصورة مباشرة (بتنسخ الصورة PNG عالية الجودة وبتنفتح محادثة الزبون دغري، أول ٣ مرات شرح اللصق، وإذا ما زبط النسخ قائمة المشاركة بلا ما تنفتح المحادثة مرتين) أو PDF (ومشاركة ملغية أو شرح مسكّر ما بينحسبوا انبعتت) |
| `sql/policies.test.sql` | قواعد الحماية بقاعدة البيانات (شو بيقدر المدير والمندوب والغريب يعملوا) والترقيم من السيرفر |

## تشغيلها على الكمبيوتر
```bash
npm install --no-save playwright && npx playwright install chromium
node tests/run.js            # كل فحوصات المتصفح
node tests/run.js sales      # ملف واحد
CPU_SLOW=4 node tests/run.js  # كأنه جهاز أبطأ 4 مرات (لتلاقي الفحوصات الحساسة للتوقيت)
PGHOST=localhost PGUSER=postgres bash tests/sql/run.sh   # قاعدة البيانات (بدها Postgres)
```
