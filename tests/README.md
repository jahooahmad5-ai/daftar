# 🧪 فحوصات دفتر

بتشتغل لحالها على GitHub مع كل تعديل (تبويب **Actions**). إذا فشل شي، بيطلع ❌ حدّ التعديل.

| الملف | شو بيفحص |
|---|---|
| `access.test.js` | شاشة القفل، موبايل المدير، باركود نقطة البيع، موبايل المندوب، دخول المدير، نقل وضع البيّاع القديم، المندوب الموقوف، خروج ومسح، إعادة ربط موبايل خسر جلسته، حفظ المبيعات يلي ما ارتفعت |
| `sales.test.js` | صندوق المندوب، القبض من زبون، الاستلام من المندوب، الترقيم بين جهازين، تصليح الرقم المكرر، التسعير حسب الزبون، مسودة الفاتورة، زر + |
| `storage-print.test.js` | نقل البيانات لـ IndexedDB والبيانات الكبيرة، النسخ الأوتوماتيكية والرجوع، أوامر الطابعة (عادي وسريع)، إيصال السند، الآلة الحاسبة |
| `security.test.js` | بيانات ملغومة جاية من السحابة أو من رابط ما بتشغّل كود، «بيانات تجريبية» ممنوعة مع السحابة، نسخة قبل «مسح الكل»، دفعة فاتورة الدولار |
| `small.test.js` | تبويبين مفتوحين بنفس الوقت، ترقيم قيود الرصيد الافتتاحي من السيرفر، السرعة مع آلاف الفواتير (والأرصدة بتطابق الحساب اليدوي) |
| `sql/policies.test.sql` | قواعد الحماية بقاعدة البيانات (شو بيقدر المدير والمندوب والغريب يعملوا) والترقيم من السيرفر |

## تشغيلها على الكمبيوتر
```bash
npm install --no-save playwright && npx playwright install chromium
node tests/run.js            # كل فحوصات المتصفح
node tests/run.js sales      # ملف واحد
PGHOST=localhost PGUSER=postgres bash tests/sql/run.sh   # قاعدة البيانات (بدها Postgres)
```
